# 一封來自寶寶的信

一個選禮物、寄出包裹並打開寶寶回信的網頁小遊戲。

## 遊玩

https://ayperos66.github.io/baby-letter-game/

直接開啟網址即可遊玩；重新整理頁面可重新開始。

## 禮物統計

打開寶寶回信後，可查看大家寄出藍色與粉紅色禮物的票數和比例。
每一輪只計第一次寄出的禮物；同一輪重玩、改色和重新連線不會重複計票。
管理員清空統計時會開始新一輪，所有人都能重新選色投一次。
清除網站資料、無痕模式或換瀏覽器會視為新紀錄，這不是登入身分驗證。

票數存放於私人 Google 試算表，公開服務僅提供彙總及匿名票據；測試票與正式票分開。
連線失敗不會阻擋遊戲，也不會把未知票數顯示成零。
